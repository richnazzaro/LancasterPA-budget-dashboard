# Configuration reference

Generated by `scripts/docs_config.py` from the JSON Schemas in `schemas/`. Do not edit by hand: change a schema's `description` or `examples` and run `python scripts/docs_config.py`.

Check every file with `python scripts/validate_config.py`. A problem is reported as one line naming the file, the field (or the CSV line and column) and what was expected.

How to read the tables: a field written `a.b` sits inside `a`; `a[].b` is a field of each item in the list `a`; `a.<name>.b` is a field of each named entry in `a`. Keys starting with `_` are comments where a schema allows them. In YAML, write `on`, `off`, `yes` and `no` in quotes (`"off"`): bare, YAML reads them as true/false.

## `site.yaml`

Settings for the whole website, shared by every government on it: the site's name, how to contact it, which governments appear and in what order, and the property-tax estimate page.

Schema: `schemas/site.schema.json`. Edited by: the site owner.

| Field | Type | Required | Meaning | Example |
|---|---|---|---|---|
| `title` | text | yes | The site's name, shown in the header and the browser tab. | `Lancaster Budget Explorer` |
| `contact_email` | text | yes | The public email address readers can write to. Never a personal address. | `budget@nazwel.net` |
| `repository` | text | yes | Web address of the project's public code repository, linked from the About page. | `https://github.com/richnazzaro/LancasterPA-budget-dashboard` |
| `default_government` | text | yes | The government the site opens on when a reader visits the home address. Must be one of the ids listed under governments. | `lancaster-city` |
| `governments` | list of text | yes | The governments on the site, in the order the City / County / School switch lists them. Each id is a folder under governments/. Only governments with data appear in the switch; with one government there is no switch. | `["lancaster-city", "lancaster-county"]` |
| `tax_estimate` | group of fields | no | The property-tax estimate page: which years it compares and where readers look up their assessed value. Leave it out and the page is not built. |  |
| `tax_estimate.rates` | text | yes | Where the website finds the tax rates file, relative to the web folder. | `data/tax_rates.json` |
| `tax_estimate.this_year` | whole number | yes | The tax year the page treats as "this year". | `2026` |
| `tax_estimate.next_year` | whole number | yes | The tax year the page treats as "next year" (the newest budget's year). | `2027` |

Schema: `schemas/csv/county_context_facts.schema.json`. Today's file(s): `data/county/context_facts.csv`.

| Field | Type | Required | Meaning | Example |
|---|---|---|---|---|
| `id` | id | yes | A stable id for the fact. | `tax_increase` |
| `group` | text | yes | Which section the fact belongs to (tax, millage_history, standing, capital, agency_grants, millage_note). | `tax` |
| `label` | text | yes | The fact's label as shown. | `Tax increase over 2025` |
| `value` | text | yes | The value (a number, or text when unit is text). | `10` |
| `unit` | choice: `percent`, `mills`, `dollars`, `rating`, `positions`, `text` | yes | percent, mills, dollars, rating, positions or text. | `percent` |
| `year` | year | yes | The year the fact is for. | `2026` |
| `fund` | text | column yes, value may be empty | The fund, where the fact is about one. | `Capital Reserve Fund` |
| `source_doc` | file name | yes | The PDF that prints it. | `County-Resolution-79-of-2025.pdf` |
| `source_page` | page number | yes | The page. | `1` |
| `source_kind` | choice: `printed`, `presentation`, `calculated` | yes | printed = in a primary document; presentation = only on a presentation slide; calculated = our sum of printed figures. | `printed` |
| `find` | text | column yes, value may be empty | The text the check looks for on the page (year\|value for a table row). | `10%` |
| `also_in` | text | column yes, value may be empty | Other places that print it: &lt;file&gt;#&lt;page&gt;, separated by ;. | `County-2026-Budget-Presentation.pdf#4` |
| `note` | text | column yes, value may be empty | A note shown with the fact. | `The audited report says the County maintained this rating during 2025.` |

### elected_offices.csv (County)

County departments headed by an elected official, with the line shown on their page and its sources.

Schema: `schemas/csv/county_elected_offices.schema.json`. Today's file(s): `data/county/elected_offices.csv`.

| Field | Type | Required | Meaning | Example |
|---|---|---|---|---|
| `department_code` | code | yes | The department code. | `A1111` |
| `department` | text | yes | The department's printed name. | `Commissioners Office` |
| `label` | text | yes | The tag shown (Elected office, Elected judges). | `Elected office` |
| `line` | text | yes | The sentence shown on the department page. | `Headed by the three elected County Commissioners` |
| `source_doc` | file name | yes | The PDF that says it. | `County-ACFR-2025.pdf` |
| `source_page` | page number | yes | The page. | `10` |
| `also_in` | text | column yes, value may be empty | Other places: &lt;file&gt;#&lt;page&gt;, separated by ;. | `County-ACFR-2025.pdf#17;County-2026-Budget-Presentation.pdf#3` |
| `note` | text | yes | The evidence, for people. | `Report p.10: "three county commissioners are elected every four yea...` |

### org_units.csv (County)

County department codes -&gt; department name and the group (by code letter) they belong to, with their pages in the budget book.

Schema: `schemas/csv/county_org_units.schema.json`. Today's file(s): `data/county/org_units.csv`.

| Field | Type | Required | Meaning | Example |
|---|---|---|---|---|
| `department_code` | code | yes | The department code. | `A1100` |
| `department` | text | yes | The department name. | `Line-Item Grants` |
| `group_letter` | letter | yes | The code's first letter. | `A` |
| `group` | text | yes | The group's name. | `General Government` |
| `book_section` | text | yes | The book section that lists it. | `Operating Department Summaries` |
| `section_page` | page number | yes | The section's first page. | `29` |
| `department_page` | page number | yes | The department's page. | `42` |
| `source_doc` | file name | yes | The book. | `County-2026-Budget-Book.pdf` |
